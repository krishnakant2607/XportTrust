# XportTrust - Export Financing Platform

A trust-first digital platform for small exporters, providing instant invoice factoring, buyer risk checking, and compliance management.

## 🚀 Quick Start

### Local Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000)

### Build for Production
```bash
npm run build
npm start
```

## 📦 Features

- **Invoice Upload & OCR** - Tesseract.js powered invoice parsing
- **Instant Factoring Offers** - Real-time buyer risk assessment
- **Escrow & Payout Flow** - Secure payment handling
- **Admin Dashboard** - Analytics and monitoring
- **Buyer Marketplace** - Global buyer connections
- **GST Refund Tracking** - Compliance management

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **Charts**: Recharts
- **OCR**: Tesseract.js
- **Font**: Montserrat

## 📄 Pages

1. `/` - Landing Page
2. `/auth/signup` - Exporter Registration
3. `/auth/signin` - Login
4. `/dashboard` - Invoice Management
5. `/admin` - Admin Analytics
6. `/marketplace` - Buyer Marketplace
7. `/compliance` - GST & Compliance Tracking
